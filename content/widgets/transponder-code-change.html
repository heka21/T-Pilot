What to notice. Every click of a digit knob is transmitted, so the order you turn them matters: 7300 to 3500 by the second digit first steps through 7400 and 7500, the unlawful interference code, while the 7 is still set. Change the 7 first and nothing alarming goes out. Remember the three as a set: 7500 unlawful interference, 7600 radio failure, 7700 emergency.

Try it: you are squawking 7300 and are cleared to squawk 3500. Which digit do you change first, and why?

The first digit. Each intermediate code is transmitted as you dial. Change the second digit first and the code steps through 7400 and 7500, the unlawful interference code, while the 7 is still set. Change the 7 to a 3 first (6300, 5300, 4300, 3300) and then the second digit (3400, 3500): none of them an emergency code.
